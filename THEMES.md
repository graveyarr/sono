# Темы Sono

Тема меняет весь Sono: цвета, размеры, шрифт, вид и место кнопок и даже сами значки. Это обычный CSS-файл (и, по желанию, папка с SVG-значками): если умеете менять цвета на сайте — сделаете и тему. Пример темы, которая меняет всё, — встроенная «Кубики» (`static/themes/blocks`): пиксельные значки, кнопки-блоки, кнопки нижнего плеера слева.

Экран «Сейчас играет» настраивается **отдельно** — «Вид «Сейчас играет»» в тех же настройках (Обычный, Горизонт, Волна, Луна или свой). Любую тему можно сочетать с любым видом. Как сделать свой вид — в разделе [«Вид «Сейчас играет»»](#вид-сейчас-играет).

## Как начать

1. «Настройки → Оформление → Тема» → **«Создать свою тему»**. Sono создаст папку «Моя тема», сразу включит её и откроет папку в Проводнике.
2. Откройте `theme.css` в любом редакторе (хоть в Блокноте), уберите `/* */` у нужной строки и поменяйте цвет.
3. Сохраните файл. Sono перечитает тему сам, примерно за секунду, перезапускать ничего не нужно.

Ненужную свою тему можно удалить: наведите на её карточку и нажмите корзину в углу (или правая кнопка → «Удалить тему»). Папка темы уходит в Корзину Windows — передумаете, восстановите её оттуда. Встроенные темы не удаляются.

Папка своих тем — `%LOCALAPPDATA%\Sono\themes` (кнопка «Открыть папку тем»). Одна тема — одна папка:

```
themes/
  Моя тема/
    theme.json    — название, автор, настройки
    theme.css     — сама тема
    preview.png   — картинка для карточки (не обязательно)
    фон.jpg       — свои картинки и шрифты (не обязательно)
    icons/        — свои значки: play.svg, pause.svg, heart.svg… (не обязательно)
```

Чтобы поделиться темой, отправьте папку целиком (например, zip-архивом). Её получатель кладёт папку в свою папку тем и нажимает «Обновить список».

## Без кода: редактор тем

«Настройки → Оформление → Тема» → **«Создать в редакторе»** (или карандаш на карточке темы). Справа открывается панель: цвета, прозрачность и скругление панелей, промежутки, шрифт, картинка фона. Sono рядом перекрашивается сразу, можно листать экраны и слушать музыку. Встроенная тема и тема из мастерской открываются копией, свою редактор правит саму.

Редактор делает обычную тему из этого же описания. При сохранении он пишет свой кусок **в конец** `theme.css` между строками `/* ==== Редактор тем Sono: начало…` и `…Редактор тем Sono: конец ==== */` и перезаписывает только его. Свои правила пишите **выше** этого куска, тогда редактор их не тронет. Положения ползунков лежат в `theme.json` в поле `"editor"`. Картинка фона и свой шрифт копируются в папку темы (`background-….jpg`, `font-….ttf`), поэтому такую тему можно отправить в мастерскую как есть.

## theme.json

```json
{
  "name": "Полночь",
  "author": "ваш ник",
  "version": "1.0",
  "description": "Пара слов о теме — видно при наведении на карточку.",
  "sono": ">=0.9.3",
  "coverColors": false,
  "preview": ["#070b16", "#18213d", "#e8eeff", "#8fb0ff"]
}
```

- **coverColors** определяет, что берётся из обложки играющего трека:
  - `true`: фон и акцент подстраиваются под обложку, как в обычной Sono;
  - `false`: ничего не берётся, цвета задаёт тема;
  - `"accent"`: из обложки только акцент (ползунок, играющий трек);
  - `"tint"`: из обложки только фон.
- **preview**: цвета карточки темы в настройках — фон, панели, текст, акцент (`#rrggbb`). Можно вместо этого положить в папку `preview.png` (или `.jpg`, `.webp`).
- **sono**: с какой версии Sono тема работает. В более старой Sono карточка будет неактивной с подсказкой «Нужна Sono …».

## Переменные

Почти все цвета Sono берутся из переменных в `:root`. Чаще всего теме хватает их одних.

| Переменная | Что это | Обычное значение |
|---|---|---|
| `--bg` | фон окна под панелями | `#0a0a0a` |
| `--fg-rgb` | цвет текста и всех полупрозрачных линий, рамок, подсветок — **три числа R G B** | `255 255 255` |
| `--text`, `--muted`, `--faint` | текст: основной, второстепенный, бледный | из `--fg-rgb` |
| `--line`, `--hover` | разделители и подсветка при наведении | из `--fg-rgb` |
| `--glass` | панели-«стёкла»: медиатека, основная панель, нижний плеер | `rgba(10, 10, 10, 0.32)` |
| `--panel` | выпадающая панель поиска и похожие | `rgba(30, 30, 30, 0.9)` |
| `--menu-bg`, `--dialog-bg` | меню «⋯» и окна-диалоги | тёмно-серые |
| `--search-bg`, `--search-bg-hover` | строка поиска | тёмно-серые |
| `--shade-rgb` | подложка «Очереди», «Текста», карточек списков и настроек — R G B | `0 0 0` |
| `--tint` | цвет фона (при `coverColors` — от обложки) | `#161616` |
| `--accent` | акцент: ползунок, играющий трек (при `coverColors` — от обложки) | `#fff` |
| `--error` | ошибки | `#ff8a80` |
| `--radius` | скругление панелей | `14px` |
| `--gap` | расстояние между панелями | `8px` |
| `--font` | шрифт | `"Segoe UI Variable Text", "Segoe UI", system-ui, sans-serif` |

`--fg-rgb` и `--shade-rgb` записываются тремя числами без запятых (`20 20 20`), а не `#141414`: из них Sono сам делает полупрозрачные оттенки.

**Светлая тема** — `--fg-rgb` тёмный, `--shade-rgb` светлый, `--glass`/`--panel`/`--menu-bg`/`--dialog-bg`/`--search-bg` светлые и `color-scheme: light`. На карточках со своим тёмным фоном (Flow, шапки плейлистов) текст должен остаться светлым — переопределите переменные текста прямо на них. Пример — встроенная тема «Светлая» (`static/themes/light/theme.css`).

## Дальше — любой CSS

После переменных можно менять любые стили Sono. Классы удобно смотреть в DevTools: запустите `python app.py`, откройте http://127.0.0.1:5000 в браузере и нажмите F12. Несколько полезных:

- `.bg-art` — размытая обложка на фоне окна (у той, что видна сейчас, есть класс `.on`);
- `.glass` — все панели, `.sidebar` — медиатека, `.main` — основная панель, `.minibar` — нижний плеер;
- `body.on-now` — открыт экран «Сейчас играет», `body.mini-mode` — мини-плеер поверх окон;
- `html[data-theme="папка-темы"]` — ваша тема включена (если нужно что-то только для неё).

**Жидкий хром и ртуть.** В Sono встроены SVG-фильтры, которые превращают сплошную фигуру в надутый металл с отражениями: `filter: url(#sono-chrome)` (текст около 30–40 px), `url(#sono-chrome-sm)` (мельче), `url(#sono-chrome-lg)` (крупные заголовки). Текст при этом должен быть сплошным (`color: #fff`, без `background-clip: text`). `url(#sono-mercury)` — белые фигуры внутри элемента сливаются, как капли ртути. Фильтры дорогие: элемент с ними не анимируйте, даже сдвигом — плавность падает в разы. Пример — встроенная тема «Хром».

**Размеры и место кнопок.** Окно — CSS-сетка (`body`: медиатека слева, основная панель справа, нижний плеер снизу), ширина медиатеки — `--sidebar`, расстояние между панелями — `--gap`. Нижний плеер `.minibar` — сетка из трёх частей: `.mini-left` (трек и ♡), `.mini-center` (кнопки и перемотка), `.mini-right` (эффекты, очередь, громкость); переставить их можно через `order` и `grid-template-columns`, кнопки внутри — через `order` и `display: none`. Кнопки-значки — `.icon-btn` (маленькие — `.icon-btn.small`), «играть» — `.play`, обычные кнопки — `.btn`, ползунки — `input[type="range"]`. Так сделано в «Кубиках»: кнопки нижнего плеера стоят слева, название — посередине.

## Свои значки

Положите в папку темы папку `icons` и SVG-файлы с именами значков — Sono заменит ими свои значки везде: в плеере, меню, списках. Не положили какой-то — останется обычный. Рисуйте цветом `currentColor` (`fill="currentColor"` или `stroke="currentColor"`) — тогда значок сам берёт цвет кнопки: обычный, при наведении, включённый.

```xml
<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 12 12" fill="currentColor" shape-rendering="crispEdges">
  <path d="M3 1h1v10H3zM4 2h1v8H4z"/>
</svg>
```

Имена значков: `play`, `pause`, `prev`, `next`, `shuffle`, `smartShuffle`, `repeat`, `repeatOne`, `queue`, `volume`, `muted`, `heart`, `heartFilled`, `dislike`, `dislikeFilled`, `plus`, `addTo` (добавить в плейлист), `more` (⋯), `close`, `back`, `chevron`, `check`, `trash`, `edit`, `download`, `downloaded`, `share`, `lyrics` (текст песни), `fx` (эффекты), `moon` (таймер сна), `clock`, `clip`, `note`, `image`, `folder`, `sort`, `sortList`, `swap`, `playNext`, `censor`, `artist`, `album`, `import`, `remove`, `home`, `search`, `flow`, `nowPlaying`, `library`, `settings`, `sidebar` (ручка медиатеки), `monitor`, `compass`, `palette`, `expand`. Полный список — ключи `icons` в `static/js/icons.js` и `data-i` в `static/index.html`.

Значки тоже очищаются: остаются только фигуры (`path`, `rect`, `circle`, `ellipse`, `line`, `polyline`, `polygon`, `g`) и их цвета и размеры. Скрипты, ссылки, картинки, `style` и `url(…)` выкидываются. Один значок — не больше 16 КБ. Поменяли файл значка — Sono перечитает его сам, как и `theme.css`.

## Вид «Сейчас играет»

Вид — такая же папка с `theme.json` и `theme.css`, но в `theme.json` стоит `"part": "now"`. Он появляется не в «Теме», а в «Виде «Сейчас играет»» и подключается поверх выбранной темы. Начать проще всего с кнопки **«Создать свой вид»** — там заготовка с примером.

- Пишите правила для `body.on-now .main` (основная панель, пока открыт этот экран) и `#view-now` (сам экран). Свои цвета объявляйте там же, а **не в `:root`** — иначе перекрасится весь Sono. Если меняете `--fg-rgb`, объявите заново и `--text`, `--muted`, `--faint`, `--line`, `--hover` (они считаются там, где объявлены).
- Цвета обложки есть всегда, даже если тема их не берёт: `var(--cover-tint, запасной цвет)` и `var(--cover-accent, запасной цвет)`. Так «Горизонт» красит небо под обложку при любой теме.
- Части плеера переставляются CSS-сеткой: `.deck` — плеер (внутри `.cover-stage` — обложка, `.np-row` с `.info` — название и `.np-actions` — кнопки, `.progress`, `.controls`, `.status`), рядом `.up-next` — «Очередь». Удобно сделать `.np-row { display: contents; }` — тогда название и кнопки становятся частями сетки сами по себе. Раскладку лучше писать для `body:not(.mobile)` (на телефоне — своя), а для открытой «Очереди»/«Текста» (`body.show-queue`, `body.show-lyrics`) проверять узкое окно.
- `html[data-now-style="папка"]` — ваш вид включён.

Примеры — встроенные «Горизонт», «Волна» и «Луна» (`static/themes/horizon`, `wave`, `moon`). До Sono 0.9.7 они были темами; если у вас была выбрана одна из них, Sono сам перенесёт выбор в «Вид «Сейчас играет»».

Классы могут меняться от версии к версии. Переменные из таблицы — постоянные: на них можно рассчитывать.

## Поделиться темой: мастерская

Готовую тему можно отправить в мастерскую — её увидят все слушатели Sono в «Настройки → Оформление → Мастерская тем»
и поставят одним щелчком. Каталог — репозиторий [graveyarr/sono-themes](https://github.com/graveyarr/sono-themes):

- без опыта с GitHub — «Предложить тему» (кнопка есть и в самой мастерской): приложите zip с папкой темы;
- через Pull Request — папка `themes/<id>/`, как описано в [CONTRIBUTING.md](https://github.com/graveyarr/sono-themes/blob/main/CONTRIBUTING.md).

Для мастерской в `theme.json` нужны ещё `version` (поднимайте при каждом изменении — иначе у людей не обновится),
`license` и `tags` (метки: «Тёмные», «Яркие», «Ретро»…), а в папке — снимок `screenshots/1.png` (16:10).
Каждую тему перед публикацией смотрит человек.

## Что тема не умеет (специально)

Тему может прислать кто угодно, поэтому Sono перед подключением её очищает:

- **никаких адресов из интернета**: `url(http://…)`, `//сайт`, абсолютные пути убираются. Иначе тема могла бы «звонить домой» и узнавать, кто и когда открыл Sono. Свои картинки и шрифты кладите в папку темы и пишите `url(фон.jpg)` — так работает. Можно и `data:image/…`;
- **`@import` не работает**: весь CSS темы — в одном `theme.css`;
- **скриптов нет**: тема — только CSS;
- файл темы — не больше 512 КБ; из папки темы Sono отдаёт только картинки (`png jpg webp gif svg avif`) и шрифты (`woff2 woff ttf otf`).

### В такт музыке и обложка как картинка

- **Удары в такт.** Строка `:root { --beat: on; }` включает для темы удары: на каждый удар баса у `<html>` меняется атрибут `data-beat` — `1`, `2`, `3`, `4` и снова `1` (`4` — каждый четвёртый, «сильная доля»). Вешайте на эти значения короткие анимации: `html[data-beat="1"] .cover-wrap { animation: тряска-а 0.15s; }`, `html[data-beat="2"] .cover-wrap { animation: тряска-б 0.15s; }`. У соседних ударов имена анимаций должны отличаться — иначе одинаковая анимация не начнётся заново. На паузе, в свёрнутом окне и при «Без анимаций» ударов нет. Пример — встроенная тема «Алукард».
- **Обложка играющего трека** есть в переменной `--cover-url` (это готовое `url(…)`): `background: var(--cover-url, url(запасная.png)) center / cover`. Так можно сделать из обложки наклейку, окно, рамку. Пока ничего не играло, переменной нет — у `<html>` в атрибуте `style` её тоже нет, и `html[style*="--cover-url"] …` позволяет показывать украшение только когда обложка есть.
- **Пиксели.** `filter: url(#sono-pixel-lg)` / `url(#sono-pixel)` / `url(#sono-pixel-sm)` разбивают элемент на квадраты 28 / 14 / 7 px. Фильтр дорогой: только для коротких переходов (например, смена обложки: `#cover.shown { animation: … }`), не для постоянной анимации.
- **Переход между экранами.** Открытый экран на время получает класс `.entering` (`#view-home`, `#view-now`, `#view-list`, `#view-settings`…) — на него можно повесить свою склейку вместо обычного появления.

### Живая полоса перемотки

Строка `#view-now { --seek-viz: live; }` в theme.css (темы или вида) заменяет полосу перемотки на экране «Сейчас играет» живыми полосками: они двигаются под музыку (тот же спектр, что у большой визуализации), сыгранная часть — цветом `--accent`. Так сделано в виде «Волна». Подвинуть или растянуть полосу можно как обычно — стилями `#view-now .progress` и `#view-now input[data-np="seek"]` (полоски рисуются ровно поверх ползунка).
